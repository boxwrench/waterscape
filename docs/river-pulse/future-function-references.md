# River Pulse future function references

These are product/function references to revisit after the v0.1 Hacienda vertical slice. They are not dependencies and do not expand the v0.1 acceptance criteria.

The map-scale corridor river is now part of the active Hacienda prototype rather than a future-function item. This file stays focused on later product expansion beyond that current slice.

## California Water Watch

Official site: https://cww.water.ca.gov/

Treat California Water Watch as a high-value reference for future River Pulse functions, especially:

- statewide → hydrologic region → HUC-8 watershed → local/station drill-down
- current conditions expressed against historical context rather than raw values alone
- streamflow, precipitation, temperature, snowpack, groundwater, reservoir, soil-moisture, and vegetation layers in one navigable water-conditions experience
- user-defined areas of interest and local watershed context
- links from summary condition views into deeper source/data views

Potential River Pulse translations include watershed overlays, precipitation/snow/soil-moisture context around a river corridor, seasonal-condition classifications, and broader multi-layer watershed views around authored places.

The reference is about product behavior and information hierarchy. Do not assume California Water Watch frontend code is an open-source dependency unless an official repository and license are identified separately.
