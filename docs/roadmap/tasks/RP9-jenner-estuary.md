# RP9: Build a photo-informed Jenner estuary and Pacific shoreline

## Scope

The user requests the best complete Jenner scene we can make: the river meeting the ocean,
using photographs, matching colors and drawing on the resource library for ocean water.
Favor recognizable composition and polished water. Keep verification proportionate per the
user's latest instruction; do not revisit the blocked RP8 deployment or publish new work
without a subsequent publication instruction. Preserve accepted Hacienda and reservoir work.

## Steps

1. Inspect actual Jenner photographs from multiple viewpoints. Record reference authors,
   URLs and licenses; do not redistribute reference photos unless separately licensed/noticed.
   Review Tidewater ocean/breaker/swashboard techniques and existing local Three water tools.
2. Build an explicitly authored coastal setting with Jenner's long sand/pebble spit, broad
   calm estuary, greener coastal bluffs, Goat Rock silhouette and open Pacific horizon.
   Match reference sand, vegetation, rock and water colors. Use bounded shore cameras and
   useful compositions for Estuary lookout, River shore and Pacific beach.
3. Implement contrasting calm estuary optics and rolling ocean swell with irregular fine
   detail, depth/shore-aware breaking foam and wet shoreline contact. These are illustrative
   presentation, not measured wave/current/tide conditions or live mouth status.
4. Reuse the existing Jenner package and USGS adapter for eligible NAVD88 water-level evidence
   at station 11467270. Explicitly preserve stale/missing evidence and source links. Do not
   convert Hacienda discharge to local water level/current or imply the scene's fixed mouth
   opening is observed today. Data remains available when graphics fail.
5. Add the Jenner entry/navigation and build inclusion. Document source/material/resource
   provenance, authored coordinate/shoreline limits and how to open the scene.
6. Run the focused checks below, inspect actual desktop/mobile rendered scene and improve
   visual problems found. Open the local preview in Firefox. Commit implementation and Result;
   no push/merge for this new task unless the user asks.

## Checks

- Focused unit tests for Jenner water-level eligibility/staleness and local shore geometry.
- `npm run test:build` (includes river package checks).
- One focused browser smoke run: all three views, reduced motion, desktop/mobile, data outage
  and GPU failure; inspect rendered screenshots. Re-run only after a relevant correction.

## Interpretation

Geometry is a photo-informed Setting reconstruction, not new DEM/bathymetry, infrastructure
survey, flood prediction or a real-time mouth-closure determination. Observation numbers are
normalized from fetched USGS records with provenance; source quantity and visual geometry
stay separate. Color/clarity, swell, foam, swash and light are illustrative/authored choices.
